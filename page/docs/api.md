# API Reference

The Direktiv API is a RESTful API that allows you to manage namespaces, workflows, instances, services, variables, secrets, and more.

## Authentication

All API requests require authentication using an API key. See the [Authentication Guide](api/authentication.md) for details on how to retrieve and use your API key.
